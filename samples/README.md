# Sample Data Templates

This directory contains sample template files used for importing bulk data into MapsShield Pro.

### Files Included:
- **Accounts:**
  - `sample_accounts.csv` — CSV format for bulk Google accounts (`email,password,2fa,backup_codes`).
  - `sample_accounts.xlsx` — Excel format for bulk Google accounts.
- **Review Links:**
  - `sample_links.csv` — CSV format for target Google Maps review URLs with category and mode.
  - `sample_links.txt` — Plain text newline-separated URLs.
- **Proxies:**
  - `sample_proxies.csv` — CSV format for HTTP/HTTPS/SOCKS5 proxies with credentials.
  - `sample_proxies.txt` — Text format for proxies (`protocol://user:pass@host:port` or `host:port:user:pass`).

You can upload any of these sample files directly via the app's respective tabs.
