# 🤖 Google Account Email Automation Agent

এই এজেন্টটি স্বয়ংক্রিয়ভাবে আপনার কম্পিউটারের Google Chrome ব্রাউজার ওপেন করবে, গুগলে লগইন করবে, Gmail-এ প্রবেশ করে প্রাপকের ইমেইল ও মেসেজ লিখে সেন্ড করে দেবে।

---

## 🚀 কীভাবে ব্যবহার করবেন?

### অপশন ১: `.env` ফাইলের মাধ্যমে (সবচেয়ে সহজ)
1. ফোল্ডারে থাকা [`.env`](file:///c:/Users/SOHEL/Desktop/google%20loging/.env) ফাইলটি ওপেন করুন।
2. আপনার তথ্যগুলো বসিয়ে দিন:
   ```env
   GOOGLE_EMAIL=আপনার_জিমেইল@gmail.com
   GOOGLE_PASSWORD=আপনার_পাসওয়ার্ড

   RECIPIENT_EMAIL=যাকে_পাঠাবেন@example.com
   EMAIL_SUBJECT=মেসেজের বিষয়
   EMAIL_MESSAGE=আপনার পাঠানো মেসেজ
   ```
3. এবার ফোল্ডারে থাকা [`run.bat`](file:///c:/Users/SOHEL/Desktop/google%20loging/run.bat) ফাইলে ডাবল-ক্লিক করুন অথবা টার্মিনালে রান করুন:
   ```bash
   node agent.js
   ```

---

### অপশন ২: টার্মিনাল প্রম্পট (ইন্টারঅ্যাক্টিভ)
যদি `.env` ফাইলে পাসওয়ার্ড না রাখতে চান, সরাসরি টার্মিনালে রান করুন:
```bash
node agent.js
```
এজেন্ট আপনাকে টার্মিনালে ইমেইল, পাসওয়ার্ড এবং মেসেজ ইনপুট দিতে বলবে।

---

## ⚠️ গুরুত্বপূর্ণ বিষয় (2-Step Verification):
* গুগল যদি আপনার ফোনে **"Is it you trying to recover/sign in?"** বা কোনো ২-স্টেপ নোটিফিকেশন পাঠায়, আপনার মোবাইলে সেটি অনুমোদন (Allow/Yes) করে দিন। এজেন্টটি ২ মিনিট পর্যন্ত স্বয়ংক্রিয়ভাবে আপনার অনুমোদনের অপেক্ষা করবে এবং সম্পন্ন হওয়া মাত্রই জিমেইলে চলে যাবে।
